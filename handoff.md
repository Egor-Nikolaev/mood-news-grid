## Что сделано

- 5 эмоциональных режимов, тон меняется прямо на карточках грида (мгновенно из кэша).
- Верификация фактов кодом (Unicode-извлечение имён/чисел/дат/цитат), контроль галлюцинаций.
- Кэш переписок адресуется хэшом текста (`textKey`) — фикс бага «чужая переписка».
- Мгновенный старт из `data/seed.json` (12 новостей, **60/60 переписок через LLM, verified**).
- Нейтралка — живой LLM-рерайт (**12/12**, ни одной копии оригинала).
- Фильтр чувствительных тем (война/жертвы/катастрофы) + детектор отказов модели → фолбэк.
- **LLM провайдер-агностичен** (`LLM_*` env): подключён **Groq** (`llama-3.3-70b-versatile`),
  живой рерайт ~1–2с; OpenRouter остался запасным вариантом одной строкой.
- Дизайн: editorial-минимализм, Inter+Lora, светлая/тёмная тема, адаптив.
- README: полная таблица по пунктам ТЗ + **раздел «Журнал разработки (как думали)»** (10 развилок).
- UI протестирован реальными кликами на проде (грид, модалка, темы, мобилка, Обновить) — 0 багов, консоль чистая.
